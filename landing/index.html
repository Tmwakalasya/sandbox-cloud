01 / THE IDEAONE WORKSPACE AT A TIME

Code needs a place
to stretch its legs.

Local machines get cluttered. Shared environments get tangled. Sandbox Cloud gives a coding task a small, separate Kubernetes workspace with its own files, limits and clock.

Send a command, watch its output, and keep working. When the workspace reaches its lifetime limit, it is removed.

03 / WHAT WE VALUESMALL SYSTEM. REAL GUARANTEES.
01 — CONTROL

State has an owner.

Kubernetes remembers which workspaces exist. The runner reports what happened inside one. The CLI does not pretend to be a database.

02 — VISIBILITY

Progress stays honest.

Scheduling, image pulls and readiness come from observed Pod state. The interface doesn’t manufacture progress.

03 — MEASURE

Make the tradeoff visible.

A local runner benchmark improved from ~55 ms to ~1.8 ms after removing an output polling delay. Cloud startup still needs a real cluster measurement.
