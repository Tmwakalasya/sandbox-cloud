GOOD QUESTIONS.

A few things
worth knowing.

Do I need a cloud account?+

No. The local setup runs K3s in Docker through k3d, using OrbStack on macOS or another compatible Docker engine. GKE is an optional deployment path.

What happens to my files?+

Files persist between commands in the same workspace. They are ephemeral: removing the Pod removes its files and in-memory command history. There is no durable run archive.

Is this a CI service?+

Not yet. Sandbox Cloud currently provides disposable workspaces and command execution. CI orchestration, GitHub-triggered builds, and automatic fix pull requests are future extensions, not current features.

Can I expose the API publicly?+

No, not safely as-is. There is no application authentication or per-user authorization. The local setup keeps the API private and connects through loopback-only Kubernetes port-forwarding.
